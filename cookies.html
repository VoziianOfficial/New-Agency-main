Overview

This Cookie Policy describes technologies that may store or read information in a visitor's browser while using the NOVA Performance website.

Depending on the technology, this may include cookies, local storage or similar browser features.

Current website build

The existing JavaScript uses local storage to remember whether the cookie notice was accepted or dismissed. No marketing or advertising tracking script is included in the current codebase.

What Are Cookies?

Cookies are small pieces of data that a website or related service may store in a browser.

Depending on how they are used, cookies can support functions such as:

  • remembering preferences;
  • maintaining sessions;
  • supporting security;
  • understanding website usage;
  • enabling advertising or measurement functionality.

Not every browser storage technology is technically a cookie. Local storage, for example, is a separate browser feature that can also remember a preference.

What This Website Currently Uses

In the current website build, the primary browser-side preference is related to the compact cookie notice displayed near the bottom of the page.

Storage Name Purpose Category
Local Storage nova-cookie-consent Remembers whether the cookie notice was accepted or dismissed so it does not repeatedly appear. Essential preference

The stored value may indicate that the notice was accepted or dismissed.

This preference is stored in the visitor's browser and is read when later pages are loaded.

Local Storage

Local storage is a browser feature that allows a website to save small values on the visitor's device without using a traditional HTTP cookie.

The current website uses it only for the cookie-notice preference.

The value is not intended to contain:

  • your name;
  • your email address;
  • your advertising account data;
  • your contact-form message;
  • passwords or credentials.

Clearing browser site data may remove this preference, which can cause the cookie notice to appear again.

Contact Forms

Information entered into a contact form is submitted to the website's form-processing endpoint.

The contact-form data itself is not stored in the nova-cookie-consent browser preference.

Information about how enquiry information may be handled is described in the Privacy Policy .

Analytics & Advertising Cookies

The current website files do not include Google Analytics, Google Ads remarketing tags, Meta Pixel or comparable behavioural tracking scripts.

If analytics, advertising pixels, conversion tags or other third-party tracking technologies are added later, this Cookie Policy should be updated to describe:

  • the provider;
  • the purpose of the technology;
  • the category of data involved;
  • whether consent is required;
  • how visitors can manage their preference.
Before adding analytics

The cookie notice and consent logic should be reviewed before introducing non-essential analytics or advertising tracking technologies.

Technical Website Data

Website hosting, security or infrastructure providers may process technical request data necessary to deliver and protect the website.

Depending on the hosting configuration, this may include:

  • IP address;
  • request time;
  • browser information;
  • requested URL;
  • server or security logs.

These technical processes are distinct from the website's cookie-notice local-storage value.

Third-Party Websites

This website may contain links to external platforms or websites.

If you follow an external link, the destination website may use its own cookies, analytics, advertising technologies or browser storage.

Those technologies are controlled by the relevant third party and are subject to that provider's own privacy and cookie information.

This Cookie Policy does not control storage technologies used after you leave this website.

Managing Browser Storage

Most modern browsers allow visitors to review or remove cookies and stored website data.

Browser settings may allow you to:

  • delete cookies;
  • clear local storage;
  • clear all site data;
  • block certain cookies;
  • control third-party cookies;
  • use private browsing modes.

Clearing local storage for this website will remove the stored cookie-notice preference.

As a result, the notice may be displayed again on a later visit.

Cookie Notice

The compact notice used by the website provides an Accept action and a close action.

Selecting either action stores the relevant preference locally so the website knows that the notice has already been handled.

In the current implementation, accepting the notice does not activate additional analytics or advertising scripts because those technologies are not included in the current project.

Changes to This Policy

This Cookie Policy may be updated if the website begins using additional browser storage, analytics tools, advertising technologies or third-party integrations.

Material changes to the tracking setup should be reflected in this policy before or when those technologies are deployed.

The date near the top of this page should be updated when the policy materially changes.
